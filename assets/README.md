# Serakki application icon

`icon-original.png` is the untouched approved 1254 × 1254 generator output with native transparency. All smaller PNGs and the multi-resolution `favicon.ico` are derived from it without cropping or changing the artwork.

Sizes: 16, 32, 48, 64, 128, 180 (Apple touch), 192, 256, 512 and 1024 pixels. ICO contains 16, 32, 48 and 256 pixel frames.

Deployment copies live in `public/` (renderer and native window), `website/assets/` (website favicons and manifest icons), and `electron/resources/icon.png` (1024 px desktop packaging source for macOS, Windows and Linux). Keep those copies synchronized when replacing this source. The full hero logo is separate and remains unchanged.
